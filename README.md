## About

I'm based in **Addis Ababa**, working at the intersection of software engineering and AI. Some days I write Python pipelines, other days I build a UI, other days I review a dataset entry for the fifth time because something feels off. I like that variety, and I'm good at all three.

Right now I spend most of my time building and reviewing **coding datasets** that go directly into LLM training pipelines. Before that, I was in India, building and deploying production systems in the fintech space.

Open to freelance work, AI roles, and anything genuinely interesting.
